# BSc Computer Science Archive

Repository สำหรับรวบรวมเนื้อหาการเรียน สรุปเนื้อหา และ Source Code จากการทำแบบฝึกหัดและงานปฏิบัติการ (Labs) ตลอดการศึกษาระดับปริญญาตรี สาขาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยธรรมศาสตร์ (CSTU)

## Repository Structure

โครงสร้างของ Repository นี้จะจัดกลุ่มตามรหัสวิชาไว้ที่ Root Directory เพื่อความยืดหยุ่นและสะดวกต่อการเข้าถึงข้อมูล

    CSTU/
    |-- CS111/
    |   |-- lectures/      # บันทึกการเรียน สไลด์ และเอกสารประกอบรายคาบ
    |   |-- labs/          # Source code สำหรับแบบฝึกหัด งานปฏิบัติการ และโปรเจกต์
    |   |-- summaries/     # ชีทสรุปเนื้อหาและ Cheat sheet สำหรับเตรียมสอบ
    |   |-- README.md      # รายละเอียดวิชา โครงสร้างคะแนน และแหล่งอ้างอิง
    |-- README.md          # สารบัญและข้อมูลภาพรวมของ Repository (ไฟล์นี้)

## Course Index

- [CS221](./CS221) - Introduction to Computer System and Organization
- [CS240](./CS240) - Principles of Data Science

- [ST329](./ST329) - Applied Probability and Statistical Models

## Workflow & Tracking

การจัดการเนื้อหาใน Repository นี้จะทำงานผ่าน GitHub Issues โดยมีการใช้งาน Issue Templates และ Labels เพื่อติดตามสถานะงาน เช่น:
- การอัปเดตเลกเชอร์ใหม่ประจำสัปดาห์
- การสร้างสรุปเนื้อหาก่อนสอบ
- การแก้ไขข้อผิดพลาดในโค้ดหรือสมุดจด (Bug & Correction)
