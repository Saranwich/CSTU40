### Abstraction (การกำหนดสาระสำคัญ)
แม้เราจะจำลองโลกความจริง **แต่เราไม่ได้ยกมาทั้งหมด** Abstraction คือการเลือกร่างพิมพ์เขียวเฉพาะสิ่งที่เรา **สนใจและจำเป็น** ต่อโปรแกรมของเราเท่านั้น
* *ตัวอย่าง:* หมาในโลกจริงมีรายละเอียดเยอะมาก (มีกรุ๊ปเลือด, อัตราการเต้นหัวใจ, จำนวนเส้นขน) แต่ถ้าเราเขียนโปรแกรม "เกมวิ่งแข่งหมา" เราจะดึงมาแค่ข้อมูลที่จำเป็น เช่น `ชื่อ`, `ความเร็ว`, และ `ความอึด` เท่านั้น

### ทำไมเราถึงต้องใช้ OOP?
* **โค้ดเป็นระเบียบ:** จัดกลุ่มตัวแปรและฟังก์ชันที่เกี่ยวข้องกันไว้ด้วยกัน โค้ดจะไม่พันกันเป็นสปาเกตตี้ ถ้ามีปัญหาตรงไหนก็ไปแก้ที่ Class นั้นทีเดียว ไม่ต้องงมหาทั้งไฟล์เอง
* **ใช้ซ้ำได้:** เขียนแม่พิมพ์แค่ครั้งเดียว เอาไปสร้างของกี่ชิ้นก็ได้ หรือจะเอาไปดัดแปลงต่อยอดในโปรเจกต์อื่นก็ทำได้ทันที ไม่ต้องก๊อปปี้โค้ดไปมา
* **ทำงานเป็นทีมจะง่ายขึ้น:** แบ่งงานกันชัดเจนได้เลยว่าใครไปเขียน Class ไหน พอเสร็จแล้วค่อยเอา Object มาประกอบร่างคุยกัน

## Class and Object

* **Class** คือ "แม่พิมพ์" กำหนดว่าสิ่งต่างๆ จะมีหน้าตาอย่างไร พฤติกรรมยังไง 
* **Object** (หรือ Instance) คือ "ของจริง" ที่ถูกสร้างขึ้นมาจากคลาสนั้นๆ จับต้องได้และดึงไปใช้งานได้จริง เราสามารถสร้าง Object กี่ชิ้นก็ได้จากแม่พิมพ์เดียว เช่น แม่พิมพ์คุกกี้ (Class) 1 อัน เอาไปปั๊มเป็นคุกกี้ (Object) ออกมาได้ 100 ชิ้น ซึ่งคุกกี้แต่ละชิ้นก็อาจจะโรยท็อปปิ้งต่างกันได้

### ข้างใน Class มีอะไรบ้าง?
องค์ประกอบหลักมี 2 อย่างได้แก่:  
1. **Attributes (คุณสมบัติ / ข้อมูล):** ตัวแปรที่เก็บสถานะหรือข้อมูลว่ามันคืออะไร เช่น ถ้าเป็นคลาส `Car` ก็จะมี สี, ยี่ห้อ, ปริมาณน้ำมัน
2. **Methods (พฤติกรรม / ฟังก์ชัน):** สิ่งที่มัน "ทำได้" เช่น สตาร์ทเครื่อง, เหยียบคันเร่ง, เบรก

### Encapsulation (การแคปซูล / การซ่อนข้อมูล)
แค่เอา Attribute กับ Method มามัดรวมกันยังไม่พอ OOP ที่ดีต้องมี **Information Hiding (การซ่อนรายละเอียด)** ด้วย เพื่อความปลอดภัยของข้อมูล
* เราต้องห่อหุ้มตัวแปรไว้ไม่ให้คนอื่นมาแก้สุ่มสี่สุ่มห้า (มักจะตั้งเป็น `private`)
* *ตัวอย่าง:* ห้ามให้ใครมาแก้พลังชีวิตมอนสเตอร์ตรงๆ แบบ `monster.hp = 9999` (มันเสี่ยงและไม่ปลอดภัย) แต่ถ้าจะลดเลือดต้องสั่งผ่าน Method ที่เราเตรียมไว้ให้เท่านั้น เช่น `monster.takeDamage(10)` เพื่อให้ Class ควบคุมความถูกต้องของข้อมูลได้เอง

## Class Diagram
ก่อนจะไปเขียนโค้ดจริง Programmer มักจะคุยกันและออกแบบโครงสร้างผ่านภาพที่เรียกว่า **UML Class Diagram** ซึ่งมักจะวาดเป็นกล่องสี่เหลี่ยมแบ่งเป็น 3 ชั้นง่ายๆ:

| ชั้นของกล่อง | ความหมาย | ตัวอย่าง (คลาส Monster) |
| :--- | :--- | :--- |
| **ชั้นบนสุด** | ชื่อ Class | `Monster` |
| **ชั้นกลาง** | Attributes (สิ่งที่คลาสจำได้) | `- hp: int`<br>`- name: String` |
| **ชั้นล่างสุด** | Methods (สิ่งที่คลาสทำได้) | `+ attack()`<br>`+ takeDamage(damage: int)` |

*(หมายเหตุ: เครื่องหมาย `-` หมายถึง private และ `+` หมายถึง public)*

## JAVA BASIC

ก่อนจะเริ่มประกาศตัวแปร เราต้องเข้าใจกฎพื้นฐานในการเขียนโค้ด Java ก่อน:

```java
// Identifiers (การตั้งชื่อ): ชื่อที่เราตั้งให้กับตัวแปร, เมธอด, หรือคลาส
int playerScore;            // ถูก
int 1stName;                // ผิด: ห้ามขึ้นต้นด้วยตัวเลข
class, public, int, ...     // ผิด: ห้ามใช้คำสงวน

// นิยมตั้งชื่อตัวแปรแบบ CamelCase:

int myMonsterHealth;
int playerScore;

// Variables (ตัวแปร):
int hp = 100;
String name = "Hero";

// Literals (ค่าคงตัว):
// ค่าข้อมูลดิบๆ ที่พิมพ์ลงไปตรงๆ
int age = 10;
double pi = 3.14;
String greeting = "Hello";
char letter = 'A';
```

## 1. Main Method (เมธอดหลัก)

ทุกโปรแกรม Java ต้องมีเมธอด `main` เป็นจุดเริ่มต้นของการทำงาน มันคือที่ที่ JVM จะเริ่มรันโค้ดของเรา

```java
public static void main(String[] args) {
    // โค้ดของโปรแกรมจะเริ่มทำงานจากตรงนี้
    System.out.println("Hello, World!");
}
```

### รายละเอียดของ main method:
- `public`: เข้าถึงได้จากทุกที่
- `static`: ไม่ต้องสร้าง object ก่อนใช้งาน
- `void`: ไม่คืนค่า
- `main`: ชื่อเมธอดที่ JVM มองหา
- `String[] args`: พารามิเตอร์สำหรับรับอาร์กิวเมนต์จาก command line

### ตัวอย่างการใช้งาน args:
```java
public static void main(String[] args) {
    if (args.length > 0) {
        System.out.println("ชื่อไฟล์: " + args[0]);
    }
    // รันด้วย: java MyProgram Hello.java
}
```

## 2. Data Types (ชนิดข้อมูล)
Java เป็นภาษาที่เข้มงวดเรื่องชนิดข้อมูลมาก (Strongly Typed) สิ่งที่เราเก็บจะถูกแบ่งออกเป็น 2 กลุ่มใหญ่ๆ:

### 2.1 Primitive Data Types (ชนิดข้อมูลพื้นฐาน)
```java
// ตัวเลขจำนวนเต็ม
int health = 100;          // ขนาด 32-bit
long money = 1_000_000L;   // ขนาด 64-bit

// ตัวเลขทศนิยม
double average = 3.14159;  // ขนาด 64-bit
float temperature = 36.5f; // ขนาด 32-bit

// ตัวอักษรเดียว
char grade = 'A';          // ต้องใส่ single quote

// ค่าความจริง
boolean isAlive = true;    // true หรือ false
```

### 2.2 Reference Data Types (ชนิดข้อมูลแบบอ้างอิง / Object)
```java
// Reference type เก็บที่อยู่ของ Object
String message = "Hello World"; // String คือ Class / Object ใน Java
```

## 3. Mathematical Expressions & Operators (การคำนวณทางคณิตศาสตร์)
```java
int sum = 5 + 3;      // บวก
int diff = 5 - 3;     // ลบ
int prod = 5 * 3;     // คูณ
int quot = 10 / 2;    // หาร
int rem = 10 % 3;     // Modulo: เอาเศษ (ผลลัพธ์ = 1)
```

### กฎลำดับความสำคัญ (Precedence Rules)
```java
// 1. วงเล็บก่อน
int result1 = (2 + 3) * 4; // 20

// 2. คูณ, หาร, Modulo
int result2 = 2 + 3 * 4;   // 14

// 3. บวก, ลบ
int result3 = 2 + 3 - 4;   // 1
```
*(ถ้าลำดับความสำคัญเท่ากัน จะทำซ้ายไปขวา)*

## 4. Data Type Conversion (การแปลงชนิดข้อมูล / Casting)

ในบางครั้งเราต้องเอาข้อมูลต่างชนิดมาคำนวณร่วมกัน (เช่น เอา `int` ไปคูณ `double`) Java จะมีการแปลงค่าอยู่ 2 แบบ:

```java
// Implicit Casting (แปลงให้อัตโนมัติ):
int a = 5;
double b = a;      // 5 -> 5.0

// Explicit Casting (บังคับแปลง / แคสต์):
double value = 3.14;
int x = (int) value; // x = 3 (ทศนิยมถูกตัดทิ้ง)
```

## 5. Input & Output เบื้องต้น (I/O)

การคุยกับผู้ใช้งานผ่านหน้าจอ (Console) เป็นสิ่งสำคัญในการสร้างโปรแกรมที่โต้ตอบได้ เราจะใช้คลาส `System.out` สำหรับแสดงผล และ `Scanner` สำหรับรับข้อมูลจากผู้ใช้

### Output (แสดงผล)
```java
// พิมพ์ข้อความโดยไม่ขึ้นบรรทัดใหม่
System.out.print("Hello ");

// พิมพ์ข้อความแล้วขึ้นบรรทัดใหม่
System.out.println("World!");  // ผลลัพธ์: Hello World!

// พิมพ์ตัวเลขและค่าต่างๆ
int age = 25;
double height = 175.5;
System.out.println("อายุ: " + age + ", ส่วนสูง: " + height);

// ใช้ printf สำหรับจัดรูปแบบการแสดงผล
System.out.printf("ชื่อ: %s, อายุ: %d ปี%n", "สมชาย", 25);
System.out.printf("ราคา: %.2f บาท%n", 123.456);  // แสดงทศนิยม 2 ตำแหน่ง
```

### Input (รับข้อมูล)
ก่อนใช้งาน `Scanner` ต้อง import คลาสก่อน:
```java
import java.util.Scanner;
```

```java
Scanner scanner = new Scanner(System.in);

// รับข้อความทั้งบรรทัด
System.out.print("กรุณาป้อนชื่อ: ");
String name = scanner.nextLine();

// รับจำนวนเต็ม
System.out.print("กรุณาป้อนอายุ: ");
int age = scanner.nextInt();

// รับจำนวนทศนิยม
System.out.print("กรุณาป้อนส่วนสูง: ");
double height = scanner.nextDouble();

// รับค่าความจริง
System.out.print("เป็นนักเรียนหรือไม่ (true/false): ");
boolean isStudent = scanner.nextBoolean();

// เคลียร์ buffer หลัง nextInt() หรือ nextDouble()
scanner.nextLine();  // เพื่อป้องกันปัญหาเมื่อรับ nextLine() ต่อ

// ปิด Scanner เมื่อใช้งานเสร็จ
scanner.close();
```

### ตัวอย่างโปรแกรม I/O ครบครัน
```java
import java.util.Scanner;

public class UserInputExample {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("กรุณาป้อนชื่อ: ");
        String name = scanner.nextLine();
        
        System.out.print("กรุณาป้อนอายุ: ");
        int age = scanner.nextInt();
        
        System.out.printf("สวัสดี %s คุณอายุ %d ปี%n", name, age);
        
        scanner.close();
    }
}
```

**ข้อควรระวัง:**
- หลังจากใช้ `nextInt()`, `nextDouble()` ควรเรียก `nextLine()` เพื่อเคลียร์ newline character
- อย่าลืมปิด `Scanner` ด้วย `close()` เพื่อป้องกัน memory leak
- `printf` ใช้ format specifiers เช่น `%s` (string), `%d` (integer), `%.2f` (float 2 decimal places), `%n` (newline)
